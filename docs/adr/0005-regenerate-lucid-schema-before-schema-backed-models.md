# Regenerate Lucid schema before schema-backed models

When adding or changing database-backed models, Watch Wise will regenerate `database/schema.ts` from the Lucid migrations before wiring the model class. For new pending migrations, run `bun ace migration:run`. When changing an existing migration file, run `bun ace migration:fresh` so the database is rebuilt from the current migration definitions before schema generation. This keeps models on the established pattern of extending generated schema classes, like `User` extends `UserSchema`, instead of duplicating generated column decorators by hand.
